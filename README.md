# 🤖 AI Resume Critic

### AI-Powered Resume & Job Match Analyzer

AI Resume Critic is a Generative AI-powered web application that analyzes a candidate's resume against a target job description. It evaluates resume compatibility, identifies missing skills and keywords, highlights strengths and weaknesses, and provides actionable recommendations for improving the resume.

The application is built using **Python, Streamlit, Gemini API, Pandas, Plotly, PyPDF2, and python-docx**.

## 📌 Project Overview

Recruiters often receive hundreds of resumes for a single position. Applicant Tracking Systems (ATS) and keyword-based screening are commonly used to identify resumes that best match a job description.

However, candidates may not know:

- How well their resume matches a particular job
- Which important skills are missing
- Which keywords they should include
- Which resume sections need improvement
- Whether their resume bullets effectively communicate their experience

**AI Resume Critic** addresses these problems by using Generative AI to compare a resume with a target job description and provide an interactive analysis.

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze resumes automatically using Generative AI.
2. Compare resumes against specific job descriptions.
3. Generate an ATS compatibility score.
4. Calculate a job-match score.
5. Identify missing keywords and skills.
6. Analyze resume strengths and weaknesses.
7. Identify weak resume bullet points.
8. Suggest improved versions of weak bullets.
9. Generate a personalized resume improvement plan.
10. Provide an interactive dashboard for users.
11. Allow users to download the analysis report.
12. Deploy the application as a web application.
